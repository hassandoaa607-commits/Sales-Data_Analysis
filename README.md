# Interactive Sales Performance Dashboard (Excel)

## Project Overview
This project involves a comprehensive analysis of sales data to monitor business performance. I built an interactive dashboard using **Advanced Excel** to transform raw data into actionable business insights.

## Key Features
* **Dynamic Visuals:** Interactive charts showing Sales by State, Category, and Segment.
* **Trend Analysis:** A monthly sales tracker to identify seasonal patterns.
* **KPI Monitoring:** Real-time tracking of Total Sales ($3.7M+), Total Profit ($3.0M+), and Total Quantity sold.
* **Product Insights:** Top-selling products analysis to support inventory management.

## Tools & Skills
* **Data Cleaning:** Using Power Query to handle and transform large datasets.
* **Data Modeling:** Building relationships between data tables.
* **Analysis:** Advanced Excel formulas and Pivot Tables.
* **Visualization:** Custom charts, Slicers (Segment/Region), and Professional UI Design.

## Actionable Insights
* Identified the top-performing states to focus marketing efforts.
* Analyzed the correlation between discounts (avg. 15%) and total profit margins.
* Provided clear visibility into category-wise performance (Furniture vs. Office Supplies vs. Technology).
